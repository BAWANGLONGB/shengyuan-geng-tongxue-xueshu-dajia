# Alien Invasion

一个零依赖、开源的 HTML5 Canvas 外星人入侵小游戏。直接打开 `index.html` 就可以玩。

## 玩法

- `Left / Right` 或 `A` / `D`：移动
- `Space`：射击
- `P`：暂停
- 手机或触屏设备可使用底部按钮

## 敌人技能

敌人会随机携带技能，命中时会弹出技能标题和说明。

- 天生爱5：大部分这类敌人会显示为 `0.5` 或 `0.x5`，受到的伤害减半，需要多打一次。
- 莫须有：前 3 次命中无敌，并播放语音“莫须有”；角标会显示剩余无敌次数。
- 指鹿为马：敌人会显示“鹿”或“马”。只有“马”会受到伤害，“鹿”被击中后会变成“马”。

玩家被击中时会短暂切换头像，过关时也会播放过关头像效果。

## 本地运行

直接用浏览器打开：

```text
index.html
```

也可以用任意静态文件服务器托管本目录。

## 文件

- `index.html`：页面结构
- `styles.css`：界面和响应式布局
- `game.js`：游戏循环、碰撞、关卡、技能和输入逻辑
- `geng.webp`、`2.png`、`3.png`：玩家头像素材
