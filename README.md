# Alien Invasion

一个零依赖、开源的 HTML5 Canvas 外星人入侵小游戏。直接打开 `index.html` 就可以玩。

## 玩法

- `←` / `→` 或 `A` / `D`：移动飞船
- `Space`：射击
- `P`：暂停
- 手机或触屏设备可使用底部按钮

## 本地运行

直接用浏览器打开：

```text
index.html
```

也可以用任意静态文件服务器托管本目录。

## 文件

- `index.html`：页面结构
- `styles.css`：界面和响应式布局
- `game.js`：游戏循环、碰撞、关卡和输入逻辑
